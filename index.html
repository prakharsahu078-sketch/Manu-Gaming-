Downloading mods

Everything you need, nothing you don’t

Built around the things players actually do: find mods, keep versions apart and get back into the game quickly.

Modrinth built in

Search mods, resource packs and shaders and install them from the launcher. Required dependencies are added for you.

Performance packs

One click installs a tuned set of Fabric performance mods, an Iris shader setup, or a CPU boost pack for chunk loading.

Separate instances

Keep each version and mod setup in its own profile. Import Fabric and Vanilla modpacks from Modrinth.

Safe mode

Switch every mod off in one click when a profile won’t start, then bring them back when you are ready.

Crash helper

Detects common startup problems such as duplicate mods or a missing Fabric API, and fixes or explains them.

Microsoft sign-in

Sign in with your Microsoft account. Optional Discord status shows what you are playing.

Questions

Is M4NU free?

Yes, the launcher is free. You need your own copy of Minecraft: Java Edition to play.

Where does it keep my data?

Instances, worlds and settings live in %USERPROFILE%\.manuxt. Don’t delete that folder unless you want to start fresh.

A profile won’t start after adding mods

Open Instances and turn on Safe mode, then add mods back a few at a time. The crash helper also reports duplicate mods and a missing Fabric API.

Does it work on Mac or Linux?

Not yet. The installer is for Windows 10 and 11.
